## 按用途选：1GB、2GB、4GB 分别能干什么

**1GB 内存**：系统本身吃掉 200–300MB，剩下的给 Nginx、一个轻量应用、几个定时任务。静态站、反向代理、爬虫、bot、学 Linux 都够。WordPress 也能装起来跑，但 MySQL 和 PHP 一忙就吃紧。

**2GB 内存**：小型 WordPress 的舒适线。数据库、PHP-FPM、Redis 缓存、面板各占一份，还能留出余量扛日常访问，这是 HostAdvice 给 WordPress 划的门槛。

**4GB 以上**：WooCommerce、多站点、Docker 跑几个容器、或者同时挂面板和邮件服务的档位。

**存储**：20–50GB NVMe 对多数小站够用，镜像和日志占不了太多。要存大量图片视频，20GB 会很快见底，这时候 30GB 的 Arcturus 比省钱更实际。

**流量**：入门档常见的额度是 1TB/月。JustHost 走的是另一套规则，不限流量但按端口限速，Sirius 和 Arcturus 给 300Mbps，Alpha Centauri 给 400Mbps，官网折算下来分别相当于每月 93TB 和 124TB 的参考值。这套规则对流量不大但偶发峰值的站点更友好，不会因为某天超了被扣钱；反过来，持续跑满带宽的业务（视频转码、公开代理、CDN 回源）会被公平使用规则限制，这类需求本来也不该买 ¥26 的机器。

**CPU**：1 核适合单线程任务，WordPress 的 PHP 执行就是单线程为主。2 核的价值在并发和后台任务，不会让页面加载快一倍。

## 常见问题

**年付一定比月付便宜吗？**
JustHost 的年付比月付便宜 20%，官网直接标出来了。代价是一次付 12 个月的总额，Sirius 那一档约 **¥313**。不确定能不能长期用，先月付一个月，确认线路和性能再补年付。

**1GB 内存到底够不够？**
够跑一个不装面板的小站。装了面板、数据库、缓存就紧张。判断标准很简单：要不要装 WordPress 或面板，要就上 2GB。

**便宜机器会不会跑路？**
看两件事：经营年限和可查的第三方记录。JustHost 官网标 21 年、第三方记录 2006 年起；RackNerd 有 Inc. 5000 记录。没有哪家能保证不跑路，所以别一次付三年，年付已经足够。

**流量真的不限吗？**
不限，但端口有限速，且标注公平共享。官网给的折算参考是 300Mbps 约每月 93TB、400Mbps 约每月 124TB，正常站点碰不到这个量级。

**只买 IPv6 的便宜档行不行？**
官网确实把免费 IPv6 当作低成本测试的卖点。做正式站点还是配 IPv4，国内访问和大量客户端对纯 IPv6 的支持都不齐。
